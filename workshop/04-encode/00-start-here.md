# Encode: Shape a Reusable Agent Skill

Use Team Canvas 5 as the team's working surface. This folder provides a digital template and a copyable drafting prompt for the shared laptop lab.

## 1. Choose the recurring point

Return to the people-and-AI working specification, workflow and team review. Choose one recurring task, decision or judgment that would benefit from guidance an agent can follow and a person can inspect.

## 2. Shape the guidance together

Complete the fields on Team Canvas 5. Agree what the skill helps with, when it applies, what it needs and produces, its repeatable procedure, principles and constraints, the human review point, uncertainty behaviour and the evidence that would count as useful.

Use [template--agent-skill.md](template--agent-skill.md) when the team wants a digital structure. Open [constraint specification](../../skills/constraint-specification/SKILL.md) only when the guidance is still too vague to follow.

## 3. Draft and inspect the file

Use [prompt--draft-guidance.md](prompt--draft-guidance.md) after the team decisions are clear. Review every returned instruction together. Start with one concise `SKILL.md`. Add `references/`, `assets/` or `scripts/` only when the skill genuinely needs reusable material that does not belong in the main instructions.

Save the skill in a folder your tool can retrieve. If the AI tool can create files, ask it to create the folder and save `SKILL.md`. Otherwise download or copy the file, then use the tool's supported upload or skill-install route. Ask the tool for its exact route rather than guessing a universal install location.

For technical detail, open the [Agent Skills specification](https://agentskills.io/specification), its [creator guidance](https://agentskills.io/skill-creation/best-practices) or the workshop [reference skills](../../skills/README.md) only when they help resolve a concrete question.

## 4. Prepare Evaluate

Agree one stable task, authorised input material and required output format. Name what evidence the team expects to inspect without assuming the skill will improve the result.

## Leave Encode with

One retrievable skill folder with `SKILL.md` and a trial-ready case.
