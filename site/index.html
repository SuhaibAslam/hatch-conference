01Orient

What real situation and judgment need attention?

Locate a recognisable friction, inspect what a plausible AI response could flatten or miss, and sharpen the critique into a usable rule.

Start with your own experience

  • SituationChoose work involving you, colleagues, users, customers or clients.
  • ConsequenceName which decision could become worse if a plausible response were trusted too quickly.
  • Judgment ruleTurn the critique into guidance a capable tool or teammate could follow.
Leave Orient withA recognisable situation, one consequence and one judgment rule.

02Coordinate

Who acts, who decides, and when should authority shift?

Map three moments in a workflow, choose an agency mode for each and name the condition that should change the mode.

Person leads

Use human judgment when consequences, context or accountability cannot be delegated.

AI leads

Let the tool prepare or act when the work is bounded, observable and easy to correct.

Work together

Make handoffs, checkpoints and changes in authority explicit.

Leave Coordinate withOne authority choice and the condition or assumption behind it.

03Specify

What challenge and working relationship are we making inspectable?

Choose one shared challenge, describe how people and AI might address it, map the flow and review what still needs attention.

ChallengeWho is affected, what is happening, and why does the consequence matter?
Working relationshipWhat becomes possible, what may AI contribute, and what stays with people?
FlowWho or what acts, what is visible, where does control change, and how can work recover?
Team reviewWhat is clear, what is unresolved, and which recurring point should the team carry forward?
Leave Specify withOne selected challenge, working specification, inspectable flow and recurring point to carry forward.

04EncodeCore laptop lab

Shape a reusable agent skill.

An agent skill is reusable guidance for a recurring task, decision or judgment. One shared laptop is enough: one person can operate the tool while teammates challenge the draft and keep the earlier decisions visible.

01

Choose the recurring point

Use Team Canvas 5 to choose one recurring task, decision or judgment from the work your team shaped. Agree what the skill should help with and when it should be used.

02

Structure the skill

Write when the skill applies, what it needs and produces, the procedure, principles, constraints, human review point, uncertainty behaviour and evidence criterion.

03

Draft, review and save

Use the team decisions to draft the file. Review every instruction together, save the result as SKILL.md and agree one stable trial case.

Leave Encode withOne retrievable SKILL.md file and a trial-ready case.Evaluate tests what changes and what the team should improve.

05EvaluateCore laptop lab

Does the skill improve the work?

Run the same task twice. The first output shows what the AI tool does without your skill. The second shows what changes when the skill is applied. Your team decides whether those differences matter.

Baseline outputThe task completed without your agent skill.

This is the starting point. Keep the task, input material and output format unchanged.

then
Guided outputThe same task completed with your agent skill.

Only the skill changes. That makes the comparison useful.

01

Prepare one fair task

Keep Canvas 6, the saved skill and the stable case visible. One person can operate the tool while teammates protect the task, input and requested format across 2 fresh conversations.

02

Run the baseline

Give a fresh conversation only the task, authorised input and required output format. Keep the target skill out, then save the complete result.

03

Run with the skill, then review

Use a second fresh conversation with the same task, input and format plus the skill. Keep both outputs visible, cite evidence for each score and decide what the skill needs next.
