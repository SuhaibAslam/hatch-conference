# Comparative Evaluation

## Purpose

Determine whether a change in guidance produced a useful difference, while keeping the review tied to evidence rather than preference.

## Set up a fair comparison

Keep the task, input material, AI tool and required output format steady. Compare named baseline and guided outputs side by side.

Choose criteria that matter to the shared challenge. The workshop defaults are:

- solves the actual task;
- applies the intended design judgment;
- makes status, control and uncertainty clear;
- handles an important edge case.

## Review the outputs

For each criterion:

1. Score the baseline and guided outputs separately.
2. Cite the exact phrase, behaviour or omission that supports each score.
3. Name one improvement and one regression or cost.

Avoid turning the review into a taste debate. Where reviewers disagree, capture the competing interpretation and the evidence that would resolve it.

## Decide what changes

Keep the parts of the skill that improved the result. Revise wording that created a regression, ambiguity or unnecessary work. End with one owner, one signal and one response for the next live use.
